## Description

Most people use Grok Bot as a coder. The people shipping the most use it as a manager: it gathers context, hands a clean brief to a cloud coding agent, checks the proof, and keeps the pull request moving while you sleep.

This is the full playbook, built from xAI's own engineering guide and the Grok Bot docs: one bot per domain, the handoff brief, closing the feedback loop, a shared PR board, routines for the night shift, and where Grok Bot is the wrong tool.

Numbers in this video (15 to 200+ cloud agents, 2,000+ PRs in a month, 4 and 3 weeks) are self-reported by the Grok Bot team.
