## Description

Most people use Grok Bot as a coder. The people shipping the most use it as a manager: it gathers context, hands a clean brief to a cloud coding agent, checks the proof, and keeps the pull request moving while you sleep.

This is the full playbook, built from xAI's own engineering guide and the Grok Bot docs:
• One bot per domain, and a role written in three layers
• The handoff brief: task, context, skills, proof, and when to stop and ask
• Closing the feedback loop: screenshots, tests, and pushing back
• A shared PR board, swept every 30 minutes, with auto-merge only for low-risk changes
• Routines for the night shift: nightly audits, the P0 watch, and the fine print
• An ops bot that turns every mistake into a playbook rule
• Where Grok Bot is the wrong tool
