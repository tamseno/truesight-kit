# TrueSight kit catalog

Generated by `node tools/render.mjs ep=episodes/_gallery catalog=1` — do not edit by hand. Pictures of everything: `docs/gallery/` (`python tools/gallery.py`).

## Looks (meta.look)

Backgrounds are soft color only (gradients, drifting light, vignette, grain). Never grids, dot screens, scanlines, radar beams or ruled paper.

| look | feel | palette | default transition |
|---|---|---|---|
| `clean` | Soft white cards on drifting pastel light. Friendly, product-launch feel. | light | lift |
| `editorial` | Magazine feel: serif headlines, hairline card outlines, warm paper tones, one red accent. Calm, authoritative. | light | slide |
| `blueprint` | Engineering night: deep navy gradients, cyan outlines, condensed DIN type, mono labels. Precise, technical. | dark | push |
| `neon` | Night-mode product film: near-black with violet and cyan glows, glowing card edges. Energetic. | dark | zoom |
| `brutal` | Neo-brutalist: flat saturated color fields, thick black outlines, hard offset shadows, heavy type. Loud, playful, confident. | light | slide |
| `glass` | Frosted panels over saturated color fields, geometric type. Premium, consumer-tech. | dark | zoom |
| `terminal` | Phosphor terminal: black-green gradients, monospace everywhere, hard cuts. Hacker, raw. | dark | cut |

## Layouts (compose "layout")

On a tall content area (vertical / Shorts) side-by-side layouts (split, hero, hero-r, thirds, cols, row, bento, columns-hero, grid, cascade) stack top-to-bottom and keep their slot names, so the same script reflows. Force it with `flow: "across"` or `flow: "down"`.

| layout | slots | params |
|---|---|---|
| `full` | One slot: the whole content area. |  |
| `center` | One centred slot of w × h. | `w` px · `h` px |
| `split` | Left / right columns. | `ratio` left share 0..1 · `gap` px |
| `stack` | Top / bottom rows. | `ratio` top share · `gap` px |
| `thirds` | Three equal columns a, b, c. | `gap` px |
| `cols` | n equal columns c0.. | `n` count · `gap` px |
| `rows` | n equal rows r0.. | `n` count · `gap` px |
| `grid` | cols × rows cells g0.. (row-major). | `cols` n · `rows` n · `gap` px |
| `bento` | Big main tile left + two stacked tiles right (side0, side1). | `ratio` main share · `gap` px |
| `bento-top` | Wide main tile on top + n small tiles below (b0..). | `n` bottom tiles · `ratio` top share · `gap` px |
| `hero` | Text column left (text) + visual right (visual). | `ratio` text share · `gap` px |
| `hero-r` | Visual left + text column right. | `ratio` visual share · `gap` px |
| `headline` | A headline band on top (head) and a body area (body) — for scenes without a title. | `head` px · `gap` px |
| `ring` | n tiles of size × size on an ellipse around the centre (n0..) + centre slot. | `n` count · `size` px · `rx` px · `ry` px |
| `cascade` | n overlapping cards stepping down-right (s0..), like a stack of windows. | `n` count · `w` card w · `h` card h · `step` [dx, dy] |
| `row` | n boxes of h height in a centred row (i0..). | `n` count · `h` px · `gap` px |
| `columns-hero` | Big statement on the left third, n stacked items on the right (k0..). | `n` items · `gap` px |

## Transitions (scene "trans")

- `lift` — default: rise + soft fade
- `slide` — push sideways (same chapter)
- `zoom` — scale settle (statements)
- `push` — vertical push
- `whip` — both frames flung sideways with motion blur (topic jump)
- `wipe` — accent panel sweeps across (chapter start)
- `cut` — hard cut (contrast, turn)

## Formats (meta.format)

One script, any platform. The format sets the canvas, the content area, caption style, element scale (ui) and the platform's safe zones. Layouts stack on tall areas and keep their slot names. Always 60 fps.

| format | canvas | what | ui | captions | safe zones (px) |
|---|---|---|---|---|---|
| `landscape` | 1920×1080 | 16:9 long-form (YouTube). 1920×1080. | 1 | pill | — |
| `vertical` | 1080×1920 | 9:16 short-form (YouTube Shorts, TikTok, Reels). 1080×1920. Keep text out of the bottom 470 px and the right 132 px (the content area already does). | 1.5 | pop | top 200, right 132, bottom 470, left 40 |
| `square` | 1080×1080 | 1:1 feed post (Instagram, LinkedIn, X). 1080×1080. | 1.15 | pill | — |
| `portrait` | 1080×1350 | 4:5 feed video (Instagram, Facebook). 1080×1350. | 1.2 | pill | — |

`vertical` is also accepted as `short`.

## Recipe archetypes (scene "type")

Ready-made scenes. They follow the look too — use one when it fits, compose when it doesn't. A "landscape only" recipe still renders in other formats (scaled into the content area, lint warns `landscape-only`) — for Shorts and feed formats build that scene with compose.

### `board` — landscape only

```
board — a work board (PR tracker / kanban). Cards land in lanes, then move between lanes on their words; a sweep
line passes over the board ("every 30 minutes") and cards pick up red flags or green checks as it checks them.
data: { cols: ["Working", "Ready for review", "Merged"], colTone?: [null, "#3a6cf4", "#8b5cf6"],
        items: [{ id: "#4821", title: "Fix onboarding crash", col: 0, at?, who?: "<cast>",
                  moves?: [{ col: 1, at, flag?: "CI failing", ok?: "Checks pass" }] }],
        sweeps?: [{ at, label?: "every 30 min" }], title? }
```

### `cards` — landscape only

```
cards — 2–4 columns of "problem → fix". The problem lands first; the fix rises into the card when spoken.
data: { items: [{ title: "Usage runs out", sub?, icon?: "key"|"shield"|..., tag?: "RISK", fix: "Keep checks cheap, cap runs", at?, fixAt? }],
        fixLabel?: "THE FIX", source? }
```

### `chapter` — all formats

```
chapter — full-screen chapter opener for long videos: a huge index numeral, the title, a one-line promise,
and the chapter rail (every chapter scene in the episode) with a marker sliding to this one. Pair with "trans": "wipe".
data: { n?: 2, title: "The handoff", sub?: "What a good brief contains", kicker?: "Chapter", short?: "Handoff" (rail label) }
```

### `chat` — all formats

```
chat — an agent-app conversation. Sidebar of bots, a thread where each message lands on its word (bots "type" first),
tool-run rows (spinner → check), skill chips, proof thumbnails, an approval card, a summary report. The thread scrolls itself.
data: { bot: "quill", sidebar?: ["quill", "jenny"], status?: "Working · cloud computer", composer?: "Message Quill…", app?: "Grok Bot",
  messages: [ { from: "you" | "<cast key>", text?, at?, time?: "07:58", typing?: true,
                chips?: ["/react-native-best-practices"], tool?: { text: "Started Cursor cloud agent", detail?: "fix/…", icon?: "bolt", doneAt?, done?: "Agent finished" },
                shots?: [{ label: "Before", bad?: true, title? }], approval?: { title, sub?, button?: "Approve", at? },
                report?: [{ k: "PRs ready", v: "14", tone?: "good"|"bad" }] } ] }
```

### `checklist` — landscape only

```
checklist — the call to action. Steps tick off; a gate unlocks at the end; resources point to the description.
data: { title?: "Start tonight", items: [{ text, sub?, at? }], gate?: { text: "Then turn on the routine", at? },
        resources?: { title?: "In the description", items: ["house-style SKILL.md", "bootstrap.sh"] } }
```

### `clock` — landscape only

```
clock — a night (or day) on a timeline. A playhead sweeps between events; the big clock follows it.
data: { from: "21:00", to: "08:00", events: [{ time: "21:00", label: "Director picks up requests", cast?, at? }], day?: false }
```

### `code` — landscape only

```
code — an editor window. Lines reveal early (or type out), focus bands light the lines being discussed while the rest
dims, diff lines (+/-) get green/red gutters, and notes pin to lines from a side column with a connector.
data: { file: "handoff-brief.md", lang?: "md"|"js"|"ts"|"py"|"sh"|"yaml", code: "line\nline", tabs?: ["role.md"],
        reveal?: "lines"|"type"|"all", typeBy?: phrase|sec, focus?: [{ lines: [3, 5], at }],
        notes?: [{ line: 4, text: "Proof is required", at, tone?: "good"|"bad"|"warn" }], diff?: true, w? }
```

### `compare` — landscape only

```
compare — before / after proof. Two screens (mock phones or images), and a review log on the right where a bot checks
the proof: a failing check rings the problem on the "after" screen and sends it back; a later check swaps in the fixed
screen and stamps it.
data: { left: { label: "Before", phone?: { title, bad: true } | image? }, right: { label: "After", phone?: {...} | image? },
        who?: "<cast>", log?: "Proof review",
        checks: [{ text: "Button still clipped at 320pt", verdict: "fail"|"pass", at?, swap?: { phone: {...} } }],
        stamp?: { text: "VERIFIED", at? } }
```

### `compose` — all formats

```
compose — a free scene assembled from the element, motion and layout libraries. This is the default way to build
a scene that doesn't match a recipe archetype: every video gets its own pictures.
data: {
  layout?: "split" | { type: "grid", cols: 3, rows: 2 },        (slots; see LAYOUTS in docs/CATALOG.md)
  els: [ { id?, el: "card", slot?: "left" | 0, box?: [x, y, w, h], x?, y?, w?, h?, z?,   (placement: slot, box, or x/y/w/h)
           ...props of the element (text, style, title, ...),
           in?: "rise@phrase" | { m, at, off, d, ...params } | "none",   (default: a fitting entrance, spread over the narration)
           do?: ["pulse@phrase", "glow@phrase+0.4", { m: "move", at: "x", to: [x, y] }],
           out?: "sink@phrase", loop?: "float" | ["float", "shimmer"],
           kids?: [...elements], layout?: ...   (el: "group" lays its kids out inside its box) } ],
  beats?: [ { at, cam: { focus: "id", z: 1.06, k: .35 } | "reset" | { x, y, z } },
            { at, focus: "id" | ["id", ...] | "all" },          (others dim back — depth of field)
            { at, do: { id: "pulse", other: "shake" } } ],
  autocam?: true    (gentle push toward each element as it enters), showSlots?: true (draw the layout's slots, for planning) }
```

### `endcard` — all formats
